# [만나요 (MANNAYO)](https://mannayo.app)

> Copy, Paste, Share, 쉽고 빠르게 표시하는 서로의 일정

**만나요**는 여러 사람이 함께 약속 가능일을 조율할 수 있는 공유 달력 서비스입니다. 복잡한 일정 조율 과정을 간단하고 직관적으로 만들어줍니다.

## 🌟 주요 기능

### 1. 간편한 달력 생성
- **빠른 생성**: 제목만 입력하면 즉시 공유 달력 생성
- **비밀번호 보호**: 민감한 일정은 비밀번호로 보호 가능
- **고유 코드**: 각 달력마다 고유한 코드가 자동 생성되어 쉬운 공유

### 2. 직관적인 일정 표시
- **원클릭 토글**: 날짜를 클릭하면 가능/불가능 상태를 즉시 표시
- **실시간 동기화**: 다른 참여자의 변경사항이 실시간으로 반영
- **시각적 구분**: 색상으로 가능/불가능/확정일을 한눈에 구분

### 3. 약속 확정 기능
- **길게 누르기**: 날짜를 길게 누르면 약속 확정일로 설정
- **장소 검색**: 주소 검색을 통해 약속 장소를 쉽게 설정
- **확정 정보 표시**: 확정된 날짜와 장소가 달력에 명확히 표시

### 4. 쉬운 공유
- **링크 공유**: 달력 코드만으로 누구나 접근 가능
- **비로그인 접근**: 회원가입 없이도 달력 조회 및 일정 표시 가능
- **소셜 미디어 최적화**: 링크 공유 시 달력 미리보기 이미지 자동 생성

### 5. 사용자 친화적 인터페이스
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모든 기기에서 최적화
- **월별 뷰**: 요일별 세로형 레이아웃으로 한 달 일정을 한눈에 파악
- **직관적인 UI**: 복잡한 설정 없이 바로 사용 가능

## 🎯 사용 시나리오

### 팀 회의 일정 조율
1. 팀장이 "팀 회의 일정" 달력을 생성
2. 생성된 코드를 팀원들에게 공유
3. 각 팀원이 자신의 가능한 날짜를 클릭하여 표시
4. 모든 일정을 확인한 후 가장 적합한 날짜로 확정

### 친구 모임 계획
1. 모임 주최자가 "친구 모임" 달력을 생성
2. 카카오톡이나 메신저로 링크 공유
3. 친구들이 각자 가능한 날짜를 표시
4. 모두가 가능한 날짜를 찾아 약속 확정

### 가족 행사 일정
1. 가족 중 한 명이 "가족 여행" 달력을 생성
2. 비밀번호를 설정하여 가족만 접근 가능하도록 보호
3. 가족 구성원들이 각자의 일정을 표시
4. 모두가 가능한 날짜를 선택하여 여행 일정 확정

## 💡 왜 만나요를 사용해야 할까요?

### ✅ 기존 일정 조율의 문제점
- 여러 사람과 메시지를 주고받으며 일정을 조율하는 번거로움
- 누가 언제 가능한지 한눈에 파악하기 어려움
- 일정 변경 시 모든 사람에게 다시 알려야 하는 불편함

### ✨ 만나요의 해결책
- **한 번의 링크 공유**로 모든 참여자가 동시에 일정 표시
- **실시간 업데이트**로 변경사항이 즉시 반영
- **시각적 달력**으로 가능한 날짜를 한눈에 확인
- **확정 기능**으로 최종 일정을 명확히 결정

## 🚀 시작하기

### 1단계: 로그인
구글 계정으로 간편하게 로그인하거나, 비로그인 상태로도 달력 조회 및 일정 표시가 가능합니다.

### 2단계: 달력 생성
"공유달력 만들기" 버튼을 클릭하고 제목을 입력하면 즉시 달력이 생성됩니다.

### 3단계: 공유하기
생성된 달력 코드를 복사하거나 링크를 공유하여 참여자들을 초대합니다.

### 4단계: 일정 조율
- 참여자들이 각자 가능한 날짜를 클릭하여 표시
- 불가능한 날짜도 클릭하여 표시 가능
- 모든 일정을 확인한 후 가장 적합한 날짜를 길게 눌러 확정
